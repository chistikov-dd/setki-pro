# Руководство по редактированию сеток

## Обзор

Режим редактирования сеток позволяет администраторам и судьям вносить изменения в турнирные сетки:
- Перетаскивать участников между матчами (drag & drop)
- Добавлять новых участников
- Удалять участников
- Заменять участников

## Права доступа

- **Администраторы**: могут редактировать любые сетки
- **Судьи**: могут редактировать только ту сетку, которую они выбрали для работы (зарезервированную за ними)

## Как использовать

### 1. Открыть режим редактирования

1. На странице выбора сеток найдите нужную сетку
2. Нажмите кнопку с иконкой карандаша (📝) справа от кнопки "Выбрать сетку"
3. Откроется экран редактирования сетки

### 2. Операции редактирования

#### Перетаскивание участников (Drag & Drop)

1. Кликните на карточку участника и удерживайте кнопку мыши
2. Перетащите участника на другую позицию
3. Отпустите кнопку мыши
4. Участники автоматически поменяются местами

**Визуальные подсказки:**
- Перетаскиваемый участник становится полупрозрачным
- Целевая позиция подсвечивается синей рамкой

#### Добавление нового участника

1. Найдите пустой слот в матче (отображается как "Пусто")
2. Нажмите кнопку "+" (зелёная иконка)
3. В модальном окне введите:
   - **Имя участника** (обязательно)
   - Название клуба (необязательно)
   - Вес в кг (необязательно)
4. Нажмите "Добавить"

#### Удаление участника

1. Найдите участника, которого нужно удалить
2. Нажмите кнопку "×" (красная иконка)
3. Подтвердите удаление во всплывающем окне
4. Участник будет удалён, позиция станет пустой

### 3. История изменений

В верхней части экрана редактирования отображается история последних 5 изменений:
- Время изменения
- Тип операции (add, remove, swap, update)
- Имя участника
- Кто внёс изменение (имя судьи или ID администратора)

### 4. Выход из режима редактирования

Нажмите кнопку "Закрыть" в правом верхнем углу. Список сеток автоматически обновится.

## Синхронизация изменений

Все изменения автоматически:
1. Сохраняются в локальную базу данных (SQLite)
2. Добавляются в очередь синхронизации
3. Отправляются на сервер:
   - **Online режим**: на setki.pro API
   - **Local Server**: на локальный сервер администратора
   - **Offline**: сохраняются локально и синхронизируются при подключении

## Ограничения

### Для судей:
- Можно редактировать только ту сетку, которая зарезервирована за вами
- При попытке редактировать чужую сетку появится ошибка: "Сетка зарезервирована другим судьёй"
- Сначала нужно выбрать сетку для работы (зарезервировать её)

### Для администраторов:
- Могут редактировать любые сетки
- Изменения помечаются ID администратора в истории

## Технические детали

### Backend (Tauri Commands)

**Новые команды:**
- `update_bracket_participant` - обновить/добавить/удалить участника
- `swap_bracket_participants` - поменять местами двух участников
- `get_bracket_edit_history` - получить историю изменений

**Параметры:**
```typescript
interface ParticipantEditRequest {
  bracket_id: number;
  match_id: number;
  participant_slot: 'participant1' | 'participant2';
  fighter_id?: number;
  fighter_name?: string;
  club_name?: string;
  weight?: number;
  operation_type: 'add' | 'update' | 'remove';
}
```

### Frontend (React)

**Store:** `bracketEditorStore.ts`
- Управление состоянием редактирования
- Drag & Drop логика
- Операции добавления/удаления/замены

**Компоненты:**
- `BracketEditor.tsx` - главный экран редактирования
- `AddParticipantModal.tsx` - модальное окно добавления участника
- Интегрирован в `BracketSelection.tsx`

### База данных (SQLite)

**Таблица:** `bracket_participant_edits`

Хранит историю всех изменений:
- ID сетки и матча
- Тип операции
- Данные участника
- Кто внёс изменение (судья или админ)
- Время изменения
- Статус синхронизации

## Примеры использования

### Сценарий 1: Замена спортсмена на турнире

1. Администратор открывает редактор сетки
2. Находит участника, который снялся
3. Нажимает "×" для удаления
4. Нажимает "+" на освободившемся месте
5. Вводит данные нового участника
6. Нажимает "Добавить"
7. Изменения автоматически синхронизируются

### Сценарий 2: Исправление ошибки в жеребьёвке

1. Судья открывает свою сетку в режиме редактирования
2. Перетаскивает участников в правильные позиции
3. Система автоматически меняет их местами
4. Закрывает редактор - изменения сохранены

### Сценарий 3: Offline турнир

1. Администратор запускает локальный сервер
2. Судья подключается к локальному серверу
3. Вносит изменения в сетку через редактор
4. Изменения сохраняются в локальной БД
5. После турнира админ переключается в online режим
6. Все изменения автоматически синхронизируются с setki.pro

## Решение проблем

### "Сетка зарезервирована другим судьёй"
**Решение:** Вы пытаетесь редактировать сетку другого судьи. Сначала выберите свою сетку.

### "Требуется авторизация"
**Решение:** Вы не авторизованы. Выполните вход как администратор или судья.

### "Матч не найден в кэше"
**Решение:** Сетка не загружена в offline кэш. Администратор должен скачать турнир через "Скачать турнир".

### Изменения не синхронизируются
**Проверьте:**
1. Есть ли подключение к интернету (для online режима)
2. Работает ли локальный сервер (для local режима)
3. Проверьте очередь синхронизации в БД (`sync_queue`)

## Горячие клавиши

В данный момент горячие клавиши не поддерживаются. Все операции выполняются через UI.
