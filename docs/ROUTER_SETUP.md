# Настройка роутера TP-Link для SETKI.PRO KEEPER

**Цель:** Настроить роутер TP-Link как локальный сервер для турниров без интернета с максимальным радиусом покрытия Wi-Fi.

**Конфигурация:**
- Режим: Только локальная сеть (без интернета)
- Безопасность: WPA2 с паролем
- Радиус: Максимальный (для больших спортзалов)
- Устройства: До 50 судейских столов

**Протестировано на:**
- TP-Link AX1500 (Wi-Fi 6) ✅
- TP-Link Archer C6 (Wi-Fi 5)
- TP-Link TL-WR841N

---

## 🎯 Краткая инструкция для TP-Link AX1500 (на основе скриншотов)

**Если у вас TP-Link AX1500 - следуйте этому краткому руководству:**

### 1. Вход в роутер
- URL: `http://192.168.0.1` или `http://tplinkwifi.net`
- Логин/Пароль: тот что вы установили при первой настройке

### 2. Wi-Fi 2.4 ГГц (основная сеть для судей)
**Путь:** Беспроводной режим → вкладка 2.4 ГГц

```
SSID: SETKI-TOURNAMENT
Защита: WPA2-PSK[AES]
Пароль: setki2025
Ширина канала 2.4 ГГц: 20/40МГц
Канал 2.4 ГГц: Auto (или 1, 6, 11)
```

### 3. Wi-Fi 5 ГГц (для лучшей производительности)
**Путь:** Беспроводной режим → вкладка 5 ГГц

```
SSID: SETKI-TOURNAMENT-5G
Защита: WPA2-PSK[AES]
Пароль: setki2025
Ширина канала 5 ГГц: 20/40/80МГц
Канал 5 ГГц: Auto
```

### 4. DHCP сервер
**Путь:** Дополнительные настройки → Сеть → DHCP-сервер

```
DHCP: Включить ✓
Начальный IP: 192.168.0.100
Конечный IP: 192.168.0.200
Шлюз: 192.168.0.1
```

### 5. Межсетевой экран (КРИТИЧНО!)
**Путь:** Дополнительные настройки → Защита → Межсетевой экран

```
Межсетевой экран SPI: Включить ✓
Ответ на ping из LAN: Включить ✓ ← ОБЯЗАТЕЛЬНО!
Ответ на ping из WAN: Выключить
```

### 6. Резервирование IP для администратора (рекомендуется)
**Путь:** Дополнительные настройки → Сеть → DHCP-сервер → вкладка "Резервирование адресов"

1. Нажмите "Добавить"
2. Выберите MAC-адрес ноутбука администратора
3. IP-адрес: `192.168.0.50`
4. Статус: Включить ✓
5. Сохранить

**Готово!** Роутер настроен для работы с SETKI.PRO KEEPER.

## Подготовка

### Что понадобится:
- ✅ Роутер TP-Link (TL-WR841N или аналогичный)
- ✅ Компьютер с Ethernet-кабелем или Wi-Fi
- ✅ 15-20 минут времени

### Шаг 0: Подключение к роутеру

**Вариант А - По кабелю (рекомендуется):**
1. Подключите Ethernet-кабель от LAN-порта роутера к компьютеру
2. Включите роутер в розетку

**Вариант Б - По Wi-Fi:**
1. Найдите наклейку на роутере с SSID (имя сети) и паролем
2. Подключитесь к Wi-Fi роутера с компьютера/ноутбука

**Проверка подключения:**
```bash
# Linux/Mac
ping 192.168.0.1
# или
ping 192.168.1.1

# Windows
ping 192.168.0.1
```

Если пинг проходит - все готово для настройки!

## Блок 1: Вход в настройки роутера

### Шаг 1.1: Открыть веб-интерфейс

1. Откройте браузер (Chrome, Firefox, Edge)
2. Введите в адресной строке:
   - `http://192.168.0.1` или
   - `http://192.168.1.1` или
   - `http://tplinkwifi.net`

3. Нажмите Enter

### Шаг 1.2: Авторизация

**Стандартные логин/пароль TP-Link:**
- Логин: `admin`
- Пароль: `admin`

Если не подходит, попробуйте:
- Логин: `admin`, Пароль: пустое поле
- Логин: `root`, Пароль: `admin`

**Важно:** После первого входа роутер может попросить создать новый пароль. Придумайте надежный пароль и запишите его!

## Блок 2: Настройка локальной сети (LAN)

### Шаг 2.1: Настроить IP-адрес роутера

**Где:** Сеть → LAN

**Настройки:**
```
IP-адрес: 192.168.1.1
Маска подсети: 255.255.255.0
```

**Зачем:** Это адрес роутера в локальной сети. Судьи будут подключаться к этому адресу для работы с SETKI.PRO KEEPER.

**Действия:**
1. Перейдите: Сеть → LAN
2. Убедитесь, что IP: `192.168.1.1`
3. Маска: `255.255.255.0`
4. Нажмите "Сохранить"

### Шаг 2.2: Настроить DHCP-сервер

**Где:** DHCP → Настройки DHCP

**Настройки:**
```
DHCP-сервер: Включить
Начальный IP-адрес: 192.168.1.100
Конечный IP-адрес: 192.168.1.150
Время аренды: 120 минут (2 часа)
Основной шлюз: 192.168.1.1
Основной DNS: 192.168.1.1
```

**Зачем:** DHCP автоматически раздает IP-адреса судейским устройствам при подключении. Диапазон 100-150 = 50 устройств.

**Действия:**
1. Перейдите: DHCP → Настройки DHCP
2. Установите галочку "Включить DHCP-сервер"
3. Начальный IP: `192.168.1.100`
4. Конечный IP: `192.168.1.150`
5. Время аренды: `120` минут
6. Нажмите "Сохранить"

## Блок 3: Настройка Wi-Fi (Максимальный радиус)

### Шаг 3.1: Основные настройки беспроводного режима

**Где:** Беспроводной режим → Настройки беспроводного режима

**Настройки:**
```
Имя сети (SSID): SETKI-KEEPER
Регион: Россия (RU)
Канал: 1 (или 6, или 11)
Режим: 11bgn mixed
Ширина канала: 40 MHz
Максимальная скорость передачи: Auto
```

**Пояснения:**

**SSID:** Имя сети, которое увидят судьи при поиске Wi-Fi. Можно назвать как угодно, например:
- `SETKI-KEEPER`
- `Турнир-WiFi`
- `СеткиПро-2025`

**Канал:** Используйте **1, 6 или 11** - они не пересекаются друг с другом. Если в спортзале много других Wi-Fi сетей:
- Установите приложение "WiFi Analyzer" на смартфон
- Посмотрите, какой канал самый свободный
- Выберите его

**Ширина канала:** 40 MHz дает больший радиус покрытия, но может быть больше помех. Если будут проблемы - переключите на 20 MHz.

**Действия:**
1. Перейдите: Беспроводной режим → Настройки беспроводного режима
2. SSID: `SETKI-KEEPER` (или ваше название)
3. Регион: `Россия`
4. Канал: `1` (или 6, или 11)
5. Режим: `11bgn mixed`
6. Ширина канала: `40 MHz`
7. Нажмите "Сохранить"

### Шаг 3.2: Максимизировать мощность передатчика

**Где:** Беспроводной режим → Дополнительные настройки

**Настройки:**
```
Мощность передатчика (TX Power): Высокая (100%)
или: High / Maximum
```

**Зачем:** Это самая важная настройка для радиуса покрытия! По умолчанию роутеры работают на 50-70% мощности. Увеличение до 100% даст +30-50% радиуса.

**Действия:**
1. Перейдите: Беспроводной режим → Дополнительные настройки
2. Найдите "Мощность передатчика" или "TX Power"
3. Установите: `Высокая` или `100%` или `High`
4. Нажмите "Сохранить"

**Важно:** Если в интерфейсе нет такой опции - это нормально для некоторых моделей TP-Link. Тогда роутер уже работает на максимуме.

### Шаг 3.3: Дополнительные настройки для стабильности

**Где:** Беспроводной режим → Дополнительные настройки

**Настройки (если доступны):**
```
Beacon Interval: 100 мс
RTS Threshold: 2347
Fragmentation Threshold: 2346
DTIM Interval: 1
WMM: Включить
Short GI: Включить
```

**Зачем:** Эти настройки улучшают стабильность соединения при большом количестве клиентов.

**Действия:**
1. Перейдите: Беспроводной режим → Дополнительные настройки
2. Если видите эти параметры - установите указанные значения
3. Если не видите - ничего страшного, пропустите этот шаг
4. Нажмите "Сохранить"

## Блок 4: Настройка безопасности WPA2

### Шаг 4.1: Установить шифрование WPA2

**Где:** Беспроводной режим → Защита беспроводного режима

**Настройки:**
```
Тип шифрования: WPA/WPA2-Personal (рекомендуется)
Версия: WPA2-PSK
Шифрование: AES
Пароль PSK: ваш_пароль (минимум 8 символов)
```

**Рекомендации для пароля:**
- Минимум 8 символов
- Легко запомнить для судей
- Примеры: `setki2025`, `турнир123`, `keeper2025`

**Действия:**
1. Перейдите: Беспроводной режим → Защита беспроводного режима
2. Выберите: `WPA/WPA2-Personal`
3. Версия: `WPA2-PSK`
4. Шифрование: `AES`
5. Пароль PSK: придумайте пароль (например: `setki2025`)
6. **ЗАПИШИТЕ ПАРОЛЬ!** Вы будете давать его судьям на турнире
7. Нажмите "Сохранить"

### Шаг 4.2: Отключить WPS (уязвимость безопасности)

**Где:** Беспроводной режим → WPS

**Настройки:**
```
WPS: Отключить (Disable)
```

**Зачем:** WPS - уязвимая функция, которая может позволить взломать сеть. На турнире она не нужна.

**Действия:**
1. Перейдите: Беспроводной режим → WPS
2. Нажмите кнопку "Отключить" или снимите галочку "Включить WPS"
3. Нажмите "Сохранить"

## Блок 5: Настройка межсетевого экрана (ВАЖНО!)

### Шаг 5.1: Настроить Firewall для локальной сети

**Где:** Дополнительные настройки → Защита → Межсетевой экран

**⚠️ КРИТИЧНО ДЛЯ РАБОТЫ SETKI.PRO KEEPER!**

**Настройки:**
```
Межсетевой экран SPI: Включить ✓ (можно оставить)
Ответ на ping из LAN: Включить ✓ (ОБЯЗАТЕЛЬНО!)
Ответ на ping из WAN: Выключить (безопасность)
```

**Зачем:**
- **Ping из LAN** нужен для диагностики подключения судей к серверу
- Если не включить - судьи не смогут проверить доступность админского ноутбука
- Сервер будет работать, но диагностика проблем станет невозможной

**Действия:**
1. Перейдите: Дополнительные настройки → Защита → Межсетевой экран
2. Убедитесь что "Ответ на ping из LAN" = **Включить** ✓
3. "Ответ на ping из WAN" = Выключить (для безопасности)
4. Нажмите "Сохранить" или "Применить"

**Проверка:**
```bash
# С любого устройства в сети попробуйте:
ping 192.168.0.1  # должен отвечать
ping 192.168.0.50 # IP админского ноутбука - должен отвечать
```

## Блок 9: Использование на турнире

### Подготовка перед турниром:

**За день до турнира:**
1. Проверьте роутер дома - подключите 2-3 устройства, убедитесь, что все работает
2. Зарядите роутер (если есть батарея) или убедитесь, что есть розетка на месте
3. Запишите на бумажку:
   - Название сети (SSID): `SETKI-KEEPER`
   - Пароль Wi-Fi: `ваш_пароль`
   - IP роутера: `192.168.1.1`

**На турнире:**

1. **Размещение роутера:**
   - Установите роутер **в центре** спортзала
   - Поставьте на высоте **1.5-2 метра** (на стол, подставку)
   - **НЕ** в углу, **НЕ** в металлическом шкафу, **НЕ** за бетонной стеной
   - **НЕ** рядом с микроволновками, холодильниками

2. **Подключение админского ноутбука:**
   - Подключите ноутбук с локальным сервером SETKI.PRO KEEPER **по кабелю** к LAN-порту роутера (самое стабильное)
   - Или по Wi-Fi, если кабеля нет

3. **Запуск локального сервера:**
   ```bash
   # На админском ноутбуке запустите локальный сервер SETKI.PRO
   # Сервер будет доступен по адресу: http://192.168.1.X:8081
   # где X - это IP админского ноутбука (например, 192.168.1.100)
   ```

4. **Инструкция для судей:**
   Распечатайте или покажите на экране:
   ```
   ИНСТРУКЦИЯ ДЛЯ СУДЕЙ - ПОДКЛЮЧЕНИЕ К SETKI.PRO KEEPER

   1. Включите Wi-Fi на планшете/ноутбуке
   2. Найдите сеть: SETKI-KEEPER
   3. Введите пароль: ваш_пароль
   4. Откройте браузер
   5. Введите адрес: http://192.168.1.X:8081
      (где X - спросите у администратора)
   6. Войдите по PIN-коду и выберите номер стола
   ```

5. **Проверка подключения судей:**
   - В админ-панели SETKI.PRO KEEPER вы увидите уведомления о подключении судей
   - Формат: "Судья Иван Иванов → стол №5"

### Проверка радиуса покрытия:

**Приложение WiFi Analyzer (Android):**
1. Установите "WiFi Analyzer" из Google Play
2. Откройте приложение
3. Найдите вашу сеть `SETKI-KEEPER`
4. Ходите по спортзалу и смотрите уровень сигнала:
   - **-30 до -50 dBm** → отлично (можно работать)
   - **-50 до -70 dBm** → хорошо (для SETKI.PRO достаточно)
   - **-70 до -80 dBm** → слабо (могут быть обрывы)
   - **-80 и ниже** → вне зоны
5. Если есть мертвые зоны - переместите роутер в другое место

## Блок 10: Решение проблем (Troubleshooting)

### Проблема 1: Не могу зайти в настройки роутера

**Решение:**
1. Проверьте подключение кабеля (если по кабелю)
2. Попробуйте другой IP: `192.168.0.1` или `192.168.1.1`
3. Попробуйте адрес: `http://tplinkwifi.net`
4. Сбросьте роутер к заводским настройкам (кнопка Reset на 10 секунд)

### Проблема 2: Забыл пароль от роутера

**Решение:**
1. Сброс к заводским настройкам:
   - Найдите кнопку Reset на роутере (маленькая дырочка)
   - Нажмите и держите 10 секунд (роутер включен)
   - Роутер перезагрузится
   - Логин: `admin`, Пароль: `admin`
2. Настройте роутер заново по этой инструкции

### Проблема 3: Слабый сигнал Wi-Fi

**Решение:**
1. Проверьте, что TX Power = 100% (Блок 3.2)
2. Переместите роутер в центр помещения
3. Поднимите роутер выше (на 1.5-2 метра)
4. Уберите препятствия (металл, бетон)
5. Измените канал на 1, 6 или 11
6. Уменьшите ширину канала до 20 MHz (если 40 MHz не помогает)

### Проблема 4: Судьи не могут подключиться (Wi-Fi есть, но нет доступа)

**Решение:**
1. Проверьте, что DHCP включен (Блок 2.2)
2. Проверьте диапазон IP (должен быть 192.168.1.100-150)
3. Перезагрузите роутер
4. Проверьте, что локальный сервер SETKI.PRO запущен на админском ноутбуке

### Проблема 5: "Номер стола уже занят"

**Решение:**
Это не проблема роутера, а приложения SETKI.PRO. Судья должен:
1. Выйти из приложения (кнопка "Выход")
2. Войти заново с другим номером стола

### Проблема 6: Медленная работа / обрывы связи

**Решение:**
1. Уменьшите количество подключенных устройств (максимум 15-20)
2. Отключите ненужные устройства от Wi-Fi
3. Проверьте помехи от других Wi-Fi сетей (смените канал)
4. Перезагрузите роутер
