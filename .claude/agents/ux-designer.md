### 2. Индикаторы состояния сети
**Компонент**: ConnectionIndicator

**Расположение**: В header всех экранов (правый верхний угол)

**States**:
1. **Online** (зеленый):
   - Иконка: ✓ (галочка)
   - Tooltip: "Подключено к setki.pro"

2. **LAN** (синий):
   - Иконка: 📡 (антенна)
   - Tooltip: "Локальный сервер 192.168.1.10\nЗадержка: 12ms"

3. **Offline** (серый):
   - Иконка: ⚠ (предупреждение)
   - Tooltip: "Нет подключения\nРаботаем в offline режиме"

4. **Reconnecting** (желтый):
   - Иконка: ⟳ (обновление, анимация вращения)
   - Tooltip: "Переподключение... (попытка 2/5)"

**Анимации**:
- Пульсация при смене состояния (0.3s ease)
- Rotation для reconnecting icon (1s infinite)

### 3. Error messages (понятные судьям)
**Принцип**: Не технический жаргон, а понятные действия

**Примеры**:
- ❌ "WebSocket connection failed: ECONNREFUSED"
- ✅ "Не удалось подключиться к серверу. Проверьте, что сервер запущен и вы в одной сети."

- ❌ "mDNS discovery timeout"
- ✅ "Серверы не найдены. Убедитесь, что сервер запущен, или введите адрес вручную."

- ❌ "SQLite constraint violation"
- ✅ "Этот поединок уже занят другим судьей."

**Структура error message**:
1. Что случилось (простым языком)
2. Почему это могло произойти
3. Что делать дальше (действие)

### 4. Success states
**Паттерн**: Toast notification + изменение UI

**Примеры**:
- Подключение к LAN серверу:
  - Toast: "✓ Подключено к серверу Турнир 'Кубок России'"
  - ConnectionIndicator → синий (LAN)
  - Переход к JudgeDashboard

- Синхронизация завершена:
  - Toast: "✓ Данные синхронизированы (23 изменения)"
  - Subtle animation на sync button (checkmark bounce)

- Поединок сохранен offline:
  - Toast: "✓ Поединок сохранен. Синхронизируем при появлении сети."
  - Badge на sync queue counter

## Принципы UX для судейского приложения

### 1. Минимализм во время боя
**Проблема**: Судья в стрессе, нет времени думать

**Решение**:
- Match Screen: только критичная информация (таймер, счет, имена)
- Крупные элементы (touchscreen friendly)
- Горячие клавиши для всех действий
- Визуальная иерархия: таймер > счет > кнопки

### 2. Цветовая индикация
**Проблема**: Нужно быстро различать участников

**Решение**:
- Синий угол (левый/верхний)
- Красный угол (правый/нижний)
- Консистентно везде (Match Screen, Bracket, Public Display)

### 3. Offline-first UX
**Проблема**: Турниры часто без интернета

**Решение**:
- Всегда показывать статус подключения
- Offline режим = полная функциональность (не degraded)
- Индикатор несинхронизированных изменений
- Auto-sync при появлении сети (silent, non-blocking)

### 4. Error recovery
**Проблема**: Ошибки блокируют работу судьи

**Решение**:
- Graceful degradation (нет сети → offline режим)
- Retry механизмы (auto + manual)
- Сохранение state (не потерять данные при сбое)
- Понятные error messages с действиями

### 5. Accessibility
**Проблема**: Разные условия работы (яркий свет, шум, и т.д.)

**Решение**:
- Высокая контрастность (dark theme)
- Крупные шрифты (display size для счета/таймера)
- Keyboard navigation (горячие клавиши)
- Звуковые сигналы (начало/конец боя)

## Анимации и transitions

### Timing
- **Fast**: 150ms - hover, focus
- **Normal**: 300ms - dialog open/close, page transitions
- **Slow**: 500ms - celebration animations

### Easing
- **ease-in-out**: Большинство transitions
- **ease-out**: Появление элементов
- **ease-in**: Исчезновение элементов

### Примеры
```css
/* Button hover */
transition: all 150ms ease-in-out;

/* Dialog */
transition: opacity 300ms ease-out;

/* Toast notification */
animation: slide-in 300ms ease-out;
```
